THE ANNALIESCE ACADEMY: what is in this folder and how to put it on Netlify

FILES
  index.html                   The whole Academy.
  manifest.webmanifest         } Let her use "Add to Home Screen" and open the
  sw.js, icon-192.png, icon-512.png }  Academy offline.
  netlify.toml                 Tells Netlify where the sync function is.
  netlify/functions/sync.mjs   The sync function. Already bundled, nothing to install.

DEPLOYING (keep the folder structure exactly as it is)
  Option A: Netlify CLI. Deploys the site and the sync function.
      npm install -g netlify-cli
      netlify login
      cd this-folder
      netlify deploy --prod --dir=.        (pick your existing site when asked)
  Option B: GitHub. Put this folder in a repository and connect it in Netlify.
      Leave the build command empty and set the publish directory to "."
  Option C: drag and drop. The Academy itself will work.
      I have not been able to confirm that a dragged folder also deploys the
      sync function. If sync does not work this way, use Option A or B.

CHECK THAT SYNC WORKS
  Parent Desk > "Start syncing". If a sync code appears, it works.
  If it says it could not reach the sync service, the function was not deployed.

USING SYNC
  1. On her main device: Parent Desk > Start syncing. Write the code down.
  2. On each other device: open the site > Parent Desk > Link this device to a
     sync code, and enter it.
  Synced: XP, coins, streaks and rewards, flashcards, Dojo, trophies, avatar,
  weekly goal, check-ins, round history.
  Not synced (stay on each device): the PIN, journal entries, spelling notes.
  Anyone with the code can read and change her progress, so keep it private.
  "Delete the cloud copy" removes it from Netlify.

OTHER THINGS TO KNOW
  - Progress from the earlier version of the site is kept and carried forward.
  - Weekend ideas are suggestions. Check opening times before going.
  - To move to Year 8: change CURRENT_YEAR_GROUP near the top of index.html and
    add a BANKS[8] question set. Year 7 totals are archived in the Parent Desk.
  - Tested with a stand-in for Netlify's storage and in a real browser.
    It has not been tested against live Netlify.
